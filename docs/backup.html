备份与恢复

核心思路：备份宿主机的数据目录（PostgreSQL + 附件）。

要备份哪些？

Docker 模式下，HOST_DATA_DIR 用于持久化（附件 + PostgreSQL 数据）。

HOST_DATA_DIR/
  attachments/
  postgres/
结论：停机备份时，备份整个 HOST_DATA_DIR 目录即可。

推荐流程（更安全）

最省心：停机备份；若需要不停机备份，使用 pg_dump 导出数据库。

cd local_server/deploy
docker compose --env-file .env.docker down

# 备份 HOST_DATA_DIR（复制/打包到其它磁盘或对象存储）

docker compose --env-file .env.docker up -d

# 不停机备份（数据库导出）
docker compose --env-file .env.docker exec -T postgres pg_dump -U ${POSTGRES_USER} ${POSTGRES_DB} > backup.sql
