备份与恢复

核心思路：备份宿主机的数据目录（SQLite + 附件）。

要备份哪些？

Docker 模式下，HOST_DATA_DIR 会挂载到容器 /app/data。

/app/data/
  database.sqlite
  attachments/
结论：备份整个 HOST_DATA_DIR 目录即可。

推荐流程（更安全）

备份/恢复前先停服务，避免 SQLite 文件不一致。

cd local_server/deploy
docker compose --env-file .env.docker down

# 备份 HOST_DATA_DIR（复制/打包到其它磁盘或对象存储）

docker compose --env-file .env.docker up -d

脚本（Windows）

仓库已提供备份/恢复脚本（DB + 附件）：

local_server/deploy/scripts/backup.ps1
local_server/deploy/scripts/restore.ps1
