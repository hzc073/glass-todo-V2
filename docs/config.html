配置

Docker 部署时常用的环境变量。完整模板在仓库：local_server/deploy/.env.docker.example。

最常用

HOST_PORT

宿主机端口（映射到容器 3000）。例：8080。

HOST_DATA_DIR

数据持久化目录（挂载到 /app/data）。建议用绝对路径。

CORS_ORIGINS

跨域白名单（逗号分隔）。上线建议不要用 *。

可选（前端与标题）

API_BASE_URL

前端请求后端地址。同源部署通常留空。

APP_TITLE

前端标题。例：Glass Todo。

USE_LOCAL_STORAGE

是否强制前端使用 LocalStorage（一般不需要）。

镜像版本

DOCKER_IMAGE

镜像名（例如 Docker Hub 用户/仓库）。

IMAGE_TAG

镜像 tag。例：latest 或版本号。
