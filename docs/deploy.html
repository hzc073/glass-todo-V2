部署

NAS / 服务器上推荐用 Docker Compose；反代或 Tunnel 时注意跨域与上传大小。

Docker Compose（推荐）

关键点：配置 HOST_PORT，并把 HOST_DATA_DIR 挂载出来做持久化。 

cd local_server/deploy
cp .env.docker.example .env.docker
# 编辑 .env.docker：HOST_PORT / HOST_DATA_DIR 等

docker compose --env-file .env.docker up -d
docker compose ps
数据目录：HOST_DATA_DIR 会挂载到容器 /app/data，里面包含 database.sqlite 与 attachments/。

反代 / Cloudflare Tunnel

建议优先“同源”（前端与后端同域名），能省掉很多跨域问题。

  • CORS：上线时把 CORS_ORIGINS 从 * 改成你的域名白名单。
  • 上传大小：Nginx 反代要设置 client_max_body_size（附件最大 50MB）。
  • 同源：同域名部署时 API_BASE_URL 通常留空。
Nginx 示例：仓库里有参考配置：local_server/deploy/nginx/glass-todo.conf。
