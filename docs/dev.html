开发与构建

前端在 flutter_app/，后端在 local_server/。

Flutter（Web）

cd flutter_app
flutter pub get

# 调试
flutter run -d chrome

# 构建
flutter build web --release

后端（Node.js）

cd local_server
npm ci
node server.js
提示：如果你是部署而不是开发，优先走 开始使用 的脚本/Docker 流程。

一键发布 Web 到后端静态目录

后端静态目录为 local_server/public/，脚本会把 Flutter Web 构建产物镜像过去。 

cd local_server\deploy
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish_flutter_web.ps1
