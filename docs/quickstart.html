开始使用

两种方式：Docker（推荐 NAS）或 Windows 绿色启动。

方式 A：Docker（推荐 NAS）

最省心：端口 + 数据目录配置好，一条命令启动。

cd local_server/deploy
cp .env.docker.example .env.docker
# 编辑 .env.docker：HOST_PORT / HOST_DATA_DIR 等

docker compose --env-file .env.docker up -d
curl http://127.0.0.1:${HOST_PORT:-3000}/health
下一步：部署细节（反代/Tunnel/注意事项）见 部署。

方式 B：Windows 绿色启动

适合本机/局域网快速跑起来，不依赖 Docker。

cd local_server\deploy
copy .env.example .env
.\run.bat

# 验证
curl http://127.0.0.1:3000/health
提示：完整说明在仓库文件 local_server/deploy/README.md。

发布 Web（把前端部署到后端）

后端会把 local_server/public/ 作为静态站点目录对外提供；一键构建并发布 Web： 

cd local_server\deploy
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\publish_flutter_web.ps1
